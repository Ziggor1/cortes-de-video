# Pasta de Trabalho

Uma pasta por canal (criada pelo `novo_canal.py`), com a subpasta `Conteudo Visual` (intro, finais, logo e `visual.json`) e uma pasta por episódio com o `.mp4` dentro.

```
Pasta de Trabalho/
└─ Meu Canal/
   ├─ Conteudo Visual/   ← intro, final 16:9, finais verticais, logo, visual.json
   └─ Episódio 01/       ← coloque aqui o vídeo .mp4
```
